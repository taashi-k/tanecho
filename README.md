# TMW タネ帳

iPhoneのSafariで動く、作詞のフレーズ出し用のローカルAIです。題材と観点を選ぶと、短いフレーズがたくさん出ます。気になったものをタップして「かご」に集めます。

生成はiPhoneの中だけで行います。題材やフレーズを外のサーバーへ送ることはありません。

## iPhoneでの準備（この順番で）

1. SafariでこのサイトのURLを開きます。
2. 共有メニューから「ホーム画面に追加」を押します。
3. **ここからはホーム画面のアプリで開きます。** Safariとホーム画面のアプリは保存場所が別です。Safariでモデルを読み込んでも、ホーム画面のアプリでは使えません。
4. Wi-Fiにつないだまま「モデルを読み込む」を押し、「準備OK」になるまで待ちます。初回は数分かかります。日本語版Gemmaが読み込めない場合は、Qwen 0.5Bで試してください。
5. 「このモデルのオフライン準備済み」と出たら、機内モードにしてアプリを開き直します。もう一度モデルを読み込み、タネをまけるか確かめます。

## 使い回し禁止ワード

公開しているのは短い初期値だけです。自分用の一覧は、アプリの「使い回し禁止ワード」欄に貼ってください。貼った内容はiPhoneの中にだけ保存され、このリポジトリには載りません。

## 保存について

- 題材・設定・かごは、iPhoneの中（このサイトの保存領域）に残ります。生成した候補の一覧は、開き直すと消えます。残したいものはかごに摘んでください。
- Safariのデータを消すと、かごもモデルも消えます。大事なかごは「まとめてコピー」で書き出してください。

## 仕組み（更新する人向け）

- `src/` にアプリ本体（`index.html`・`sw.js`・`icon.png`）があります。
- `main` に push すると、GitHub Actionsが WebLLM 0.2.86 を取ってきます。それを `webllm.js` と `worker.js` にまとめ、GitHub Pagesに公開します。実行時は外部のサイトからプログラムを読み込みません。
- アプリを更新するときは、`src/sw.js` の `VERSION` を変えてください。モデルの保存データは消えません。
